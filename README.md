# SkinFind - Skincare Review Information Retrieval System

## 1. Project Overview

SkinFind is an Information Retrieval (IR) project that helps users search and explore skincare product reviews. The system retrieves relevant reviews based on user queries.

The project will use text preprocessing and TF-IDF to rank review documents according to query relevance. Aspect-based search and sentiment analysis will be explored if supported by the selected dataset.

## 2. Project Objectives

- Build a searchable collection of skincare product reviews.
- Clean and preprocess review text.
- Implement TF-IDF-based information retrieval.
- Rank documents by relevance to a query.
- Explore aspect-based search when supported by the data.
- Evaluate retrieval performance using appropriate metrics.
- Build a web interface using Streamlit.

## 3. Planned Technologies
